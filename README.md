# SmileCare Dental Website

A modern, professional, and fully interactive dental clinic website built with React, Vite, Tailwind CSS, and Framer Motion.

## Features

### 🏠 Homepage
- Eye-catching hero section with animated elements
- Animated statistics counter (5000+ smiles treated, etc.)
- Services preview cards
- Testimonials carousel
- Before/After interactive slider

### 👥 About Us Page
- Clinic philosophy and mission
- Animated timeline of clinic history
- Core values section
- Team member profiles with hover effects

### 🦷 Services Page
- Comprehensive service listings with expandable accordions
- Each service includes:
  - Icon with rotation animation
  - Description
  - Pricing
  - "Book This Service" CTA
- Services include:
  - Teeth Whitening
  - Root Canal
  - Braces/Invisalign
  - Dental Implants
  - Preventive Care
  - Cosmetic Dentistry

### 📸 Gallery
- Category filtering (All, Our Clinic, Results, Our Team)
- Lightbox with zoom animation
- Smooth transitions between categories

### 📅 Appointment Booking System
- Complete booking form with:
  - Personal information
  - Service selection
  - Date/time picker
  - Real-time validation
  - Success animation with confetti effect
- Quick contact options (Phone & WhatsApp)

### 💬 Testimonials
- Auto-scrolling carousel
- 5-star ratings display
- Patient stories
- Google Reviews integration badge

### 🎨 Before/After Gallery
- Interactive drag slider to compare before/after results
- Thumbnail navigation
- Multiple transformation examples

### 📞 Contact Page
- Contact information cards with icons
- Google Maps placeholder
- Emergency contact section
- Business hours

### 🎯 Additional Features
- Sticky header with smooth navigation
- Mobile-responsive hamburger menu
- Floating WhatsApp button with ping animation
- Smooth page transitions
- Scroll-triggered animations
- Hover effects and micro-interactions
- Professional footer with social links

## Technical Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Routing:** React Router DOM (client-side)

## Performance Features

- Optimized bundle size
- Lazy loading ready
- Smooth 60fps animations
- Mobile-first responsive design
- Fast page transitions

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
